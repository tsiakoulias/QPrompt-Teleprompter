## Patch  _(fill when fixing)_

Duplicate of `001-CUR-N01` (same defect, same function). Fixed in the same commit.

- **Root cause:** `search()`'s regex branch wrapped around the document even when called
  with `loop=false`; only `replaceAll` passes `loop=false`, so regex Replace All re-found
  matches forever when the replacement also matched the pattern. See `001-CUR-N01` for the
  full trace.
- **Fix:** Gate the regex wrap-around on `loop` (documenthandler.cpp:1552), matching the
  plain-text branch.
- **Files changed:** `src/documenthandler.cpp` (1 line).
- **Verification:** Static; interactive find unaffected (uses `loop=true`). Regex Replace All
  now terminates.
- **Commit / PR:** `56cd3ec` on `fix/replace-all-regex-loop`.
